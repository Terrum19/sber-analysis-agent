# Демо-датасеты

Небольшие синтетические CSV для тестов и сценариев чекпоинта 2.
Перегенерировать: `python ../../scripts/seed_demo_data.py` (из этой папки)
или `python scripts/seed_demo_data.py` из корня репозитория.

- `demo_users.csv` — 100 пользователей: id, регион, дата регистрации
- `demo_events.csv` — 500 событий: id, user_id, сумма, дата (12 месяцев)

Связь только через пересечение идентификаторов (`user_id`), как в кейсе.
